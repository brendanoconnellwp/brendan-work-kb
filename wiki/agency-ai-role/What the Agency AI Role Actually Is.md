# What the Agency AI Role Actually Is

> You're not being hired as "the AI person." You're being hired to rewire how an agency operates — using AI as the lever.

## Overview

The role sits at the intersection of operations, technology, and change management. In 2026 language, it's closest to an **AI Agent Orchestration Specialist** — but in a small-to-medium agency context, it's more practical and hands-on than that title suggests.

You're not building AI products. You're making an existing team of designers, developers, and project managers dramatically more effective by embedding AI into their actual workflows. The five responsibilities this typically covers map to a clear scope:

| Responsibility | What It Really Means |
|---|---|
| Workflow audits | Map the design-to-dev pipeline end-to-end, find where time and money leak, identify what AI can compress |
| Claude-powered dev processes | Set up Claude Code as part of the dev workflow — code generation, review, CI/CD integration |
| Automations (n8n) | Build internal ops automations — approvals, notifications, data sync, reporting |
| Figma MCP integrations | Connect design tools directly to dev tools so handoff stops being a bottleneck |
| Team adoption | The hardest part — getting humans to actually change how they work |

## The Real Job Description

**Phase 1: Audit & Map (Weeks 1–4)**
Walk the entire pipeline from client brief → design → dev → QA → delivery. Interview each role. Find the friction points — they're usually in handoffs, not in individual work. Common agency leaks:
- Designers producing files devs can't efficiently translate
- Specs living in Figma comments that nobody reads
- PMs manually tracking status across 4 tools
- Developers rebuilding components that already exist in the design system
- No single source of truth for project state

**Phase 2: Quick Wins (Weeks 2–6)**
Deploy automations that save visible time immediately — this builds trust:
- [[n8n for Agency Ops]] workflows for status updates, Slack notifications, approvals
- Claude Code for boilerplate generation, code review, test writing
- Basic Figma MCP setup so devs can pull design tokens directly

**Phase 3: Deep Integration (Months 2–4)**
- Full [[Figma MCP Design-to-Code Pipeline]] setup
- [[Claude-Powered Dev Workflows]] standardized across the team
- Custom n8n workflows for the agency's specific ops patterns
- Training sessions and documentation

**Phase 4: Culture Shift (Ongoing)**
- [[Getting Agency Teams to Actually Use AI]] — the adoption playbook
- Measure and report ROI
- Iterate based on what's working vs. what's gathering dust

## What Makes This Role High-Stakes at a Premium Agency

At a quality-focused small agency, the constraints are specific:
- **Quality bar is non-negotiable** — AI can't make the work worse, even by 1%
- **Client perception matters** — some clients love hearing about AI workflows, others get nervous
- **Creative ego is real** — senior designers don't want to feel replaced
- **Billing model tension** — if AI makes work faster, does the agency bill less? (Answer: no — you bill the same and invest the saved hours in higher-quality thinking)

The job isn't to maximize automation. It's to raise the ceiling on what the same team can produce.

## Compensation Context

AI automation roles in 2026 range from $70K (entry) to $150K+ (experienced). An agency-specific role with the breadth described here — touching ops, dev, design, and change management — sits at the higher end, especially if you can demonstrate ROI.
